HUMAN-AI INTERACTION · DECISION SUPPORT · MITRE

Air Traffic Control Decision Support & LLM Research

Exploring Large Language Model integration and user interface design for air traffic control decision support tools.

← All projects

Overview

Conducted research at The MITRE Corporation focused on evaluating untrained Large Language Models (LLM) for air traffic control (ATC) domain content. The project also aimed to optimize decision support user interfaces to assist controllers with complex situational awareness and operational decision-making.

Note on Documentation: Due to security guidelines and proprietary restrictions associated with my work at MITRE, specific UI screenshots, system architectures, prompt datasets, and source code cannot be publicly displayed.

My Contribution

LLM Integration & Prompt Engineering

  • LLM Prompt Optimization: Prompt-engineered 3 different general LLMs to parse high-density aviation text into human readable takeaways, developing an algorithm to rank the information by relevance and severity.
  • Subject Matter Experts (SME) Collaboration: In conjuction with SMEs, developed specialized prompt strategies to improve response accuracy, minimize model hallucination, and display only operationally relevant parsed data.

User Interface & Experience Design

  • Decision Support UI Design: Developed user interface prototype using Python to present AI insights and ML model recommendations clearly under high-cognitive-load operational scenarios.
  • Human-AI Interaction Testing: Evaluated controller workflows to streamline information presentation, optimize human-factors-related color-coding, and reduce cognitive load for operators.

Key Takeaways

Enhanced expertise in designing human-centered AI interfaces for safety-critical domain applications, evaluating LLM behavior in complex regulatory environments, and optimizing UI/UX patterns for rapid human-in-the-loop decision-making.
