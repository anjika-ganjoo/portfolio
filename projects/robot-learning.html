ROBOT LEARNING · ML · JOHNS HOPKINS APL

Vision-Language-Action Model Training

Developing pipeline for and training Vision-Language-Action (VLA) models for robotic arm manipulation using the open-source LeRobot framework.

← All projects

Overview

Developed as part of my work at the Johns Hopkins University Applied Physics Laboratory (JHU APL), the objective of this project was to train robot VLA policies capable of complex manipulation tasks while creating reusable onboarding infrastructure for other teams at the lab to leverage.

Note on Documentation: Due to security guidelines associated with my work at JHU APL, images, raw datasets, code, and CAD schematics cannot be publicly displayed.

My Contribution

  • Hardware & Embedded Systems: Worked directly with CAN bus communication protocols, low-level motor drivers, and Linux environments to interface physical hardware and set up robot arms.
  • Teleoperation & Policy Training: Developed config files in Python for the commercial arms to allow them to interface with LeRobot, then conducted teleoperation dataset collection sessions and trained over 4 different VLA policies using over 20 different datasets, achieving over 80% task completion rates along with robust scene generalization.
  • Cross-Team Onboarding Documentation: Authored comprehensive technical documentation and setup guides, making the hardware integration, teleoperation workflows, and training pipeline easily accessible and usable for other research groups across the lab.

Key Takeaways

Gained experience working with Python and Linux for robotic arm operation and VLA model training.
