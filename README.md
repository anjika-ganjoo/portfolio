# Anjika Ganjoo — Portfolio Website

A static portfolio built with HTML, CSS, and JavaScript using a clean, responsive layout. Designed to publish with GitHub Pages.

## Files
- `index.html` — homepage, project cards, experience, about, and contact sections
- `assets/css/main.css` — all site styling and responsive rules
- `assets/js/main.js` — mobile menu and dynamic footer year
- `projects/` — individual project detail pages
- `images/` — project photos, CAD renders, and headshot
- `resume.pdf` — current PDF resume


## Publish with GitHub Pages
1. Create a GitHub repository (for example, `anjika-portfolio`).
2. Upload all files and folders in this project to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Wait for the Pages deployment and open the URL shown in Settings → Pages.
